## AZ IA dans l'UI

AZ IA doit rester visible et accessible (bouton/FAB) depuis les écrans principaux, pas seulement un écran caché dans un menu — cf. le FAB déjà ajouté dans `lib/screens/main_dashboard.dart`. Toute nouvelle action qu'un écran expose et qu'AZ IA pourrait aussi exécuter via un outil (`functions/azia/tools/`) devrait, à terme, être proposée depuis le chat AZ IA — mais ça se construit module par module (voir jalons M0→M8 dans la mémoire projet), pas en une fois.
