## Méthode de travail

1. Analyser le besoin.
2. Analyser l'existant (code, modèles de données, patterns déjà en place).
3. Identifier les impacts sur les autres modules.
4. Proposer la meilleure solution (mode plan pour tout changement non-trivial).
5. Développer.
6. Tester (analyze, compilation, émulateurs Firebase quand pertinent).
7. Documenter les décisions non-évidentes.
